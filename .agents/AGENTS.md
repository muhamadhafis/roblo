# AGENTS.md — Workspace Protocol

Pedoman kerja agen AI di repositori NomNom Throw:
- Stack: Bun + Elysia (Backend), Next.js / R3F (Frontend), PostgreSQL (port 5444), Redis (port 6444).
- Hard caps: Food level max 100, Pull-up level max 100, inventory 50-200.
- Mandatory test files: Setiap fitur wajib memiliki test alur bisnis dan security/anti-cheat di direktori `tests/`.
- No commit / push otomatis tanpa persetujuan eksplisit.
